RGM Profile Editor — Quick Start Guide

        

        
      

      

        

          
1. Filter by Target OS (iOS, macOS, tvOS, visionOS, watchOS)

          
Use the platform selector at the top of the left sidebar to show only policies compatible with your target Apple OS. Selecting a specific OS also sets TargetDeviceType automatically in your exported profile.

        

        

          
2. Supervision & UAMDM Requirements

          
Payloads marked Supervision Required require devices enrolled via Automated Device Enrollment (ADE / DEP) or supervised via Apple Configurator. Payloads marked Supervised / UAMDM Keys work on unsupervised devices for basic settings, while advanced restrictions require supervision or User-Approved MDM.

        

        

          
3. Resetting Without Reloading & Dark Mode

          
Click New / Reset in the top bar at any time to clear all active settings and start a brand-new profile without refreshing the browser. Use the Moon/Sun icon to toggle Dark Mode.
