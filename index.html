RGM Profile Editor — Quick Start Guide

        

        
      

      

        

          
1. Standard Profile (.mobileconfig)

          
Use this mode to configure Wi-Fi, Passcode, Restrictions, VPN, Certificates, TCC Privacy, or macOS app settings (Chrome, Edge, Firefox, Outlook, Zoom). Click Download .mobileconfig when finished.

        

        

          
2. Declarative DDM (JSON & .mobileconfig)

          
Apple's modern Declarative Device Management lets devices evaluate rules autonomously. Export raw JSON for your MDM server, or click Download .mobileconfig to wrap your declarations inside Apple's com.apple.declarations profile format for local installation (iOS 17+ / macOS 14+).

        

        

          
3. Editing Existing Profiles

          
Have an existing .mobileconfig file? Click Import File in the top-right corner to load it into the visual form editor, tweak any setting, and re-download.
